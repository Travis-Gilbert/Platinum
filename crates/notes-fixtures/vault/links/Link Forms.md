# Link Forms

## Wikilinks

- Plain: [[Headings Target]]
- With the extension: [[Headings Target.md]]
- With the folder: [[links/Headings Target]]
- Heading: [[Headings Target#Second heading]]
- Nested headings: [[Headings Target#First heading#Nested heading]]
- Heading in this note: [[#Wikilinks]]
- Block: [[Blocks Target#^quote-block]]
- Block in a list item: [[Blocks Target#^list-item]]
- Block in this note: [[#^own-block]]
- Alias: [[Headings Target|display text]]
- Alias on a heading: [[Headings Target#Second heading|the second heading]]
- Alias on a block: [[Blocks Target#^quote-block|a quoted block]]
- Several on one line: [[Aliases]], [[Mentions]] and [[Dead End]].
- Same name in two folders, ambiguous from here: [[Note]]
- Told apart by folder: [[a/Note]] and [[b/Note]]
- Headings of the twins: [[a/Note#Shared heading]] and [[b/Note#Shared heading]]
- A file name that differs in case: [[headings target]]
- An alias, which is not a file name: [[Start]]
- Accents and CJK in a file name: [[Unicode é 日本]]
- A PDF page: [[sample.pdf#page=2]]
- A canvas: [[Board.canvas]]
- A base: [[Notes.base]]
- An image: [[pixel.png]]

A paragraph with its own block id. ^own-block
