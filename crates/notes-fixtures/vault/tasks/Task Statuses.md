# Task Statuses

- [ ] To do
- [x] Done
- [X] Done with a capital
- [/] In progress
- [-] Cancelled
- [>] Forwarded
- [<] Scheduled
- [?] Question
- [!] Important
- [*] Star
- ["] Quote
- [l] Location
- [b] Bookmark
- [i] Information
- [S] Savings
- [I] Idea
- [p] Pro
- [c] Con
- [f] Fire
- [k] Key
- [w] Win
- [u] Up
- [d] Down
- [😀] An emoji between the brackets

## Nested

- [ ] Parent
  - [x] Child done
  - [ ] Child open
    - [/] Grandchild

## Other bullets and contexts

1. [ ] Numbered task
* [ ] Star bullet task
+ [ ] Plus bullet task

> - [ ] Task in a quote

> [!todo] A callout with a task
> - [ ] Task in a callout

## With details

- [ ] Call the plumber #errand [[Dead End]] 🗓️ 2026-11-01
- [ ] Task with a tag #task-tag, a link [[Headings Target]] and a field [due:: 2026-11-02]
- [x] Completed [completion:: 2026-10-20]
- [ ] A task with a block id ^task-block

## Not tasks

- [] No space between the brackets
- [  ] Two spaces
-[ ] No space after the dash
[ ] No bullet
