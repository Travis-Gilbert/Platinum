# Footnotes

A reference footnote.[^1] A named one.[^named] The first one again.[^1]

An inline footnote.^[This text is written in place.] And a second one^[With **bold** and a [[Dead End]] link.].

A reference to a definition that does not exist.[^undefined]

[^1]: The first footnote, used twice.
[^named]: A named footnote.

    It has a second paragraph, indented four spaces.

[^unused]: A definition that nothing references.
